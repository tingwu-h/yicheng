## 运行与限制

解压后运行 npm ci，再运行 npm run dev，访问 http://127.0.0.1:5180/ 。若端口已被本项目使用，直接访问已运行服务，不必重复启动。

当前仍为本地演示数据机制，未新增生产数据库或跨设备组队服务。不同端口的浏览器存储互相隔离，因此 5180 不会自动读取 5178 的本地账号数据。压缩包不包含 node_modules、用户浏览器数据。
