# 驿程-vh0.3 更新说明

## 版本概览

- 基础项目：驿程-vh0.2
- 模型来源：用户提供的驿程-VL1.0 压缩包
- 更新重点：补齐 VL1.0 中的景点 3D 模型、许可文件、模型目录和馆区切换配置。
- 合并方式：独立生成 vh0.3；vh0.2、VL1.0 原项目与原压缩包均保留。

## 保留与范围

- vh0.2 的行程、宠物、任务、服饰和后台配置功能保留。
- 模型仍为建筑、道路、地形/绿地等场景要素，不代表兵马俑单体或历史建筑的精细复原；范围和数据源以各模型许可及 `MODEL_EXPORT_PROGRESS.md` 为准。
- 小雁塔及模型进度表中其他标注“待导出”的景点没有新增模型，本次未自行生成模型。
- vh0.2 任务配置内部版本标识保持 vh0.2，避免影响现有任务配置兼容性；应用外显版本为 vh0.3。

## 萌宠与服饰升级迭代

- 图鉴内的“官方核心任务链”入口改为“萌宠获取指南”，并将解锁说明改为轻松、可跳过的引导语。
- 萌宠与服饰均支持 Lv.1–Lv.3。萌宠升级消耗 80 / 160 枚任务金币；服饰升级消耗 40 / 80 枚任务金币。
- 各级效果限于称号、专属话术、装饰纹样与展示光效，不提供任务或金币收益加成。升级消费写入现有金币流水。
- 本地存档结构升至 v3；旧数据缺少等级时以 Lv.1 显示，原有任务、库存、解锁记录与金币流水保留。内测档所有萌宠及服饰默认 Lv.3。

## 景点图片状态

- 本次未将景点照片加入项目。Wikimedia Commons 搜索接口在首次返回后触发访问频率限制，无法核验并下载其余景点的对应图片与授权。
- 页面仍使用现有占位图；未使用随机图库图片冒充特定景点实景。该项标记为未完成。

## 自定义照片形象

- 个人中心的虚拟形象编辑新增“上传照片”模式，支持本地图片预览、替换、移除和保存。
- 选择照片后在浏览器内居中裁成 512×512 方形并压缩为 JPEG，最大原图 12 MB。
- 照片数据沿用现有 `changan-banlv-state-v1` 本地存储，刷新后保留；当前不会上传服务器。
- 保存的照片头像复用于个人资料、帖子、评论和社区等现有头像展示位置。
- 页面说明照片头像会出现在个人资料与社区内容中；清除照片后可切回虚拟形象。
- 修复切换同行萌宠后详情预览仍保留上一只宠物的问题，选中状态和主展示即时同步。
